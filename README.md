IMPORTANTE:

Vou fornecer 3 imagens/criativos do próprio produto como referência visual. USE ESSAS IMAGENS NA PÁGINA, preservando a qualidade e proporção delas. Não recrie os materiais das imagens com IA e não altere textos, capas ou elementos presentes nelas.

Também vou fornecer um site de referência visual:

https://tarefas-de-fono.vercel.app/

Use esse site SOMENTE como referência de estrutura, organização, hierarquia visual, experiência de usuário e estilo de landing page.

NÃO copie literalmente textos, código, identidade visual, marca ou conteúdo do site de referência.

A página final deve ser ORIGINAL, mas pode seguir uma lógica visual semelhante.

OBJETIVO DA LANDING PAGE

==================================================

A página deve ser curta, objetiva e altamente focada em conversão.

Não quero um site institucional.

Não quero menu complexo.

Não quero várias páginas.

Quero uma LANDING PAGE DE VENDAS.

A pessoa deve entrar, entender rapidamente:

1. O que é o produto;

2. Para quem é;

3. O que ela recebe;

4. Como pode utilizar;

5. O que existe dentro do material;

6. Quanto custa;

7. E clicar para comprar.

A comunicação deve trabalhar principalmente a dor de quem precisa preparar atividades constantemente e acaba gastando tempo procurando, criando ou organizando materiais para seus atendimentos.

A mensagem deve mostrar que o produto reúne materiais prontos e organizados em um único lugar.

Evitar exageros e promessas irreais.

A identidade visual deve ser inspirada diretamente nas 3 artes fornecidas.

- alegre;

- colorido;

- moderno;

- amigável;

- visual de material pedagógico/fonoaudiológico;

Cores predominantes inspiradas nas artes:

- azul petróleo / azul escuro;

- amarelo;

- branco/off-white;

- turquesa;

- rosa;

- verde;

- laranja.

Use cores vibrantes nos detalhes, mas mantenha o fundo predominantemente claro para não deixar a página poluída.

Não exagerar em animações.
